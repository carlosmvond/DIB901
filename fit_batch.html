Origen de los datos

Los datos corresponden a la biomasa \(x(t)\) de un cultivo batch simulado con el siguiente sistema de EDOs:

\(\dfrac{dx}{dt} = \mu_0\, S\, x, \qquad \dfrac{dS}{dt} = -\dfrac{1}{Y}\,\mu_0\, S\, x\)

donde \(x\) es la concentración de biomasa (g/L) y \(S\) es la concentración de sustrato (g/L). Se añadió ruido gaussiano \(\mathcal{N}(0, 0.15^2)\) a las observaciones de biomasa. Solo se mide \(x(t)\) — el sustrato \(S(t)\) no se observa.

Modelos a ajustar

Logístico — solución analítica cerrada, 3 parámetros: \(r, K, x_0\).

Batch (EDO) — integración numérica de las EDOs en cada evaluación, 4 parámetros: \(\mu_0, Y, x_0, S_0\).
